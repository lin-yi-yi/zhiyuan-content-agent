# P1 模型调用追溯验收 · 2026-10-03

本轮目标：关联内容任务、步骤及显式重试，保留实际指令版本、用量和配置价格下的估算，并把已完成的项目成果更新到 GitHub 开发分支。

## 已实现

- 每次模型请求保存任务/步骤/工作流尝试、逻辑调用组、请求序号与请求原因；格式回退、JSON 修复和工作流重试分别可查。
- 使用实际 system 指令 hash 作为指令版本。日志与接口不保存或导出原始提示词、回复、异常正文和凭证。
- 可选价格配置按供应商/模型精确匹配，保存价格版本和十进制估算；缺失、失败、非法配置及超精度情况保留 `null`，已知零仍为零。SDK 隐式网络重试已关闭。
- 任务调用接口支持分页、完整记录汇总和组织隔离；未知用量/费用及不同币种不强行求总额。历史未关联日志不猜测归属。
- 本地旧库与组织旧库补列迁移；任务页显示调用明细，并在步骤/状态变化时刷新，避免秒级时间戳相同造成旧数据停留。

## 边界

未调用真实付费模型，未验证供应商账单、客户材料、客户验收、收款或 ROI。金额只覆盖已记录对话模型请求的配置估算，不覆盖 embedding、外部工具、人工、税费或基础设施。记录为尽力写入，不能作为完整账本；日志缺口不能按零费用处理。
