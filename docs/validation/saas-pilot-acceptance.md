## 本轮完成

- 中文业务首页、桌面侧栏、移动端导航；招聘资料移至项目与学习。新增登录、账号、组织切换、团队、连接和用量页面。

后端 SaaS 专项包括账号 40、套餐连接 21、应用隔离 19、运维 18、安全回归 23 项；其余为原有知识、证据、内容流程等回归。存在 1 条已有 Starlette/TestClient 的 httpx 弃用提示，不影响结果。

关键证据：

- 16 个并发请求争用 7 个额度，恰好 7 个成功；同请求并发只预留一次；重复结算只生效一次。
- 两组织使用相同文档和片段编号，SQL 与真实 Qdrant 存储仍隔离。此专项使用合成 embedding，只证明隔离，不代表语义效果。
- 真实后台内容工作流与另一组织聊天交错执行，任务、素材和模型日志保持在对应组织。
- 成员撤销立即拒绝新业务请求；旧会话启动页可以恢复到仍有资格的组织。编辑不能审核，只读不能修改。
- 禁用模型后不能复用已缓存客户端；禁用外部信源不返回旧缓存、不再发外部读取。AIHOT 无运营授权不能通过组织开关启用。
- 知识额度已满时去重和同文档重建允许，新文档拒绝；组织数量最后名额和成员最后名额并发仅一个成功。
- CSRF、其他 Origin、错误组织、模型异常脱敏与额度退款、审计归属均通过。

审阅修复：操作权限/计量不再依赖数字编号的单一写法；`auto_score` 使用严格布尔类型；正文编辑不能通过回传旧 approved 状态保留旧批准。新增回归验证。实例组织记录最多 100，每账号 active owner 组织最多 3，可由环境参数下调；这不是吞吐或客户规模承诺。

## 浏览器实际流程

Chrome 上创建本机合成账号和演示组织，重启后会话继续有效。完成：

1. 登录进入业务首页；连接中心明确展示 AIHOT 待授权、远程模型未配置、飞书/企业微信规划中。
2. 启用组织 GitHub 连接，在信源台实际获取 LangChain 20 条维护者发布元数据，保留版本和原文链接；未导入发布正文。
3. 粘贴自编「星河产品知识与售后规则」，真实 FastEmbed `BAAI/bge-small-zh-v1.5` 建立 1 份文档、1 个片段及独立 Qdrant 索引。
4. 问保修期限与首次响应时间，真实语义检索最高分 0.8436，返回原文摘录、文档名和 `[chunk:1]` 引用。回答明确未调用在线生成模型；分数不是正确率。
5. 运行内容任务，真实后台流程完成 11 步后等待人工审核；审核后 12/12 步完成、状态 approved。生成使用本地规则与摘录，不代表在线大模型的生成质量。
6. 实际下载内容 ZIP，解包完整性通过；含 2 张 900×1200 PNG、正文等文案，正文保留引用。查看导出图片确认内容可读。审核清单与任务批准分别显示；导出文件本身不是审批凭证，当前没有强制批准后才能下载的服务端门禁。
7. 创建第二组织：首页知识数 0、任务 0、额度 100；切回第一组织，资料 1、任务 1、用量 2、剩余 98。两组织连接与用量互不继承。
8. 查看团队成员；在 390×844 视口检查团队表格、邀请表单和导航抽屉，正文宽度为 390，没有页面水平溢出。表格在自身容器滚动；验收后恢复桌面视口。

导出时一次旧页面因新构建替换动态模块而失败；刷新到最终构建后实际下载并检查成功。开发迭代切换页面资源不算业务成功；下载验收使用当时已刷新构建的实际下载文件。之后仅增加组织选择的刷新记忆，已另行重新构建并回归请求隔离；没有改动导出逻辑。

## 当前尚未验收或交付

- 公网域名、HTTPS 反向代理、目标服务器负载与真实客户试点；当前仅 loopback 本机运行。
- Docker CLI 未安装，Compose 和嵌入命令只有静态解析检查，没有容器构建与运行证明。
- 新 SaaS 环境没有配置在线模型密钥，本轮未调用任何在线生成模型。兼容接口与配置门禁已测试，供应商账号、余额、网络及生成质量需要运营另行验收。
- AIHOT 商业授权、真实支付/退款/发票、邮件验证、密码找回、MFA、分布式队列、监控告警、自动迁移和保留/删除策略尚未完成。
- 审核为用户声明，允许所有者自审；资料事实与许可不由系统自动认证。Obsidian 是手动文件导入，飞书/企业微信未接通。

本轮可交付为小团队试点基础，不能把这些本地证据表述为成熟公网商用、合规认证或客户收益。
