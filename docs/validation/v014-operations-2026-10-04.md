## 磁盘 CLI 实际演练

用真实 `TemporaryDirectory` 建立 database、vectors、backup、saas 四个目录，放入合成文件及 SQLite。通过子进程以隔离标准库模式调用 `scripts/ops_health.py`，依次验证：

1. 低阈值下所有目录正常，退出码 0。
2. 提高阈值到高于磁盘容量后所有目录低空间，退出码 1。
3. 低空间与缺失路径同时存在，整体未知优先，退出码 2，同时保留逐项结果。
4. 将普通文件用作目录，返回 `NOT_DIRECTORY` 和未知。
5. 非法角色参数返回固定错误 JSON，不回显路径或异常文本。
6. 恢复原阈值后再次正常，退出码 0。

前后比较文件内容 SHA-256、目录及文件的 mode/mtime_ns，合成树没有改变；标准错误为空，输出没有临时路径或文件内容。这里改变的是阈值，没有实际填满磁盘，也没有触发数据库写入 ENOSPC。读数仅代表检查时所在文件系统的可用空间，不证明 inode、配额、写权限、未来写入或业务健康。

容量数字及临时运行细节留在私有忽略目录。共享文件系统的多个角色没有叠加成总容量，未知不填成零或通过。[命令与处置](../ops-health.md)包含运行前后检查及新目录恢复要求。

## 页面与业务浏览器验收

使用 Playwright CLI 独立 Chrome 会话和 `scripts/browser_regression_server.py --port 8789` 临时服务。知识库为空，没有预先入库资料；后端固定 lexical/local 并拒绝外部连接，浏览器只允许该本机服务。没有使用用户的 Chrome 登录会话。

| 操作 | 实际观察 |
| --- | --- |
| 页面输入超过 1000 字的合成问题后提问 | 真实 FastAPI 返回 HTTP 422；页面 32 位编号与响应头、私有服务日志中的 `http_response` 编号和状态一致 |
| 点击复制 | 在独立浏览器上下文授予剪贴板权限后成功，读取自己刚写入的剪贴板，内容仅为编号 |
| 注入剪贴板拒绝 | 页面显示手动选取提示；聚焦只读输入框选中全部 32 位，编号仍保留 |
| 延迟复制完成后修改问题 | 旧错误和编号清除；释放旧复制 Promise 后，没有旧成功提示回写 |
| 空知识库提交短问题 | 真实 HTTP 200 的证据不足拒答，没有 HTTP 失败排错组件 |
| 再次触发长问题错误 | 新编号不同于旧编号，复制状态恢复初始值；最终编号再次与服务日志匹配 |
| 延迟知识库列表并注入 HTTP 500 | 加载期间先输入问题，再返回带合成编号的 500；错误与编号仍显示，继续编辑不会吞掉加载故障 |
| 375 × 900 窄屏 | 修正全局字号覆盖后，编号 32 位完整显示并可全选，输入框 scrollWidth/clientWidth 均为 267，无页面横向溢出 |

HTTP 422 来自实际应用，KB 500 和剪贴板拒绝/延迟是浏览器故障注入，不是实际服务故障或操作系统权限撤销。单元回归还覆盖检索配置失败后 KB 加载成功、无效预选库改选有效库、初始化 scope/unmount 清理；这些额外回调场景没有全部进行浏览器操作。没有 SaaS 登录或组织切换页面验收。

最终源码的隔离前端构建通过。截图在忽略目录 `output/playwright/v014/`：`real-http-422.png`、`delayed-initialization-failure.png`、`mobile-copy-fallback-final.png`。初次窄屏输入框被全局 14px 字号覆盖，调整组件选择器并设窄屏 12px 后实测通过。控制台记录的错误为主动触发的三次 422 与注入的一次 500，没有额外 JavaScript 异常；不称为控制台零错误。
