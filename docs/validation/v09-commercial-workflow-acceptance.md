日期：2026-09-19。工作目录 `/path/to/ai-content-agent`，分支 `codex/job-ready-agent-v06`。在已有未提交开发内容上继续修改，没有重置旧数据或发布到公网。

## 本轮完成

- 商业前台收敛为工作台、品牌与资料、内容任务、审核交付、效果复盘。学习、岗位、架构入口退出；旧页面地址回工作台。学习和作品集接口从主应用取消挂载，历史源文件和文档保留。
- 品牌档案有界输入、版本冲突检查、归档、知识库绑定和任务生成策略。组织隔离沿用已有服务端边界；品牌档案本身不是权限隔离单元。
- 三种固定图文模板：专业知识、产品与服务答疑、真实案例。创建时冻结品牌与模板；模板要求实际进入选题和正文提示，资料仍是唯一事实依据。
- 审核与交付检查品牌禁用表述。逐行、不区分大小写的字面匹配，不声称识别全部语义风险。
- 正式交付单验证批准状态、正文及卡片快照、当前引用有效性；导出 Markdown 正文、出处、品牌版本、审核时间和人工发布清单。PNG/ZIP 图片继续在稿件页单独导出。
- 证据稿不再补充旧账号的 AI 提效标题、标签或虚构审核声明；异常正文不能靠填充文字通过引用检查。
- 修复离开任务页后旧请求拉回页面、品牌冲突恢复、品牌深链定位、品牌入口默认模型选择。手机导航和表单保持可用。

## 浏览器与实际模型验收

使用独立端口 8767、独立 SQLite 和向量目录 `.data/v09-acceptance/`，不写入日常工作库。所有资料、品牌及产品均为合成测试内容。

1. 经实际资料接口导入「合成试点资料｜星舟 S1 巡检服务说明」，返回 201，文档编号 1，建立中文 BGE 语义索引。
2. Chrome 创建「合成试点 · 星舟巡检」品牌，保存第 1 版；修改语气后再次保存，实际显示第 2 版。
3. 从品牌按钮进入任务，正确带入品牌、绑定资料库和版本。选择「产品与服务答疑」，使用已配置 DeepSeek 模型；仅发送合成任务及检索片段。
4. 任务 1 生成草稿 1、4 张卡片，进入待审核。正文按要求回答是否替代检修、断网限制和导出方式，保留 `[chunk:1]`、`[chunk:2]` 引用与合成资料声明，未补写价格或效果指标。非人工审核步骤耗时合计约 19.5 秒，属单次观察，不是性能承诺。
5. 浏览器录入仅用于合成验收的审核备注，审批通过；出现下载交付清单入口。实际下载 `交付清单-任务1.md`，与服务生成的 Markdown 内容逐字一致（1,192 字符）；正式交付 API 返回 200，品牌快照 v2、2 条出处、manual 发布方式。
6. 品牌深链 `#brands?brand=1` 正确打开编辑页。390×844 窄屏检查品牌和最终任务页，页面宽度与滚动宽度均为 390；导航展开、进入内容任务、自动收起均成功。临时视口恢复。

证据：`.data/v09-acceptance/run.json`、`brands.json`、`delivery.json`、`approved-delivery.md`。这些是合成验收记录，不是客户案例。模型自评分 58/100，不代表客户质量验收通过；自动风险提示也不能证明事实、版权或平台合规。观察到旧风险提示出现过“无需 AIGC 标识”等越权判断，本轮已收紧风险提示词，要求只给待核对问题并禁止此类肯定结论；提示词约束不能代替人工审核。

## 五分钟操作路径

1. 在品牌与资料导入有权使用的文档并确认入库，创建品牌并绑定该资料库。
2. 用品牌创建内容，选择一个固定模板，写清本次目标和边界；在线模型需要先在设置中配置。
3. 阅读草稿及引用，必要时编辑原稿并重新审核；通过后下载正式清单，再去稿件页导出卡片。用户在官方平台手工发布后，记录实际链接和效果。

商业判断、价格实验与后续投资门槛见 [商业化计划](../v09-commercialization-plan.md)。
