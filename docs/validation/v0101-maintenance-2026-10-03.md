## 仍然存在的边界

SQLite 运行锁是本机 advisory 文件锁，不是分布式或多 worker 方案，也不保护 MySQL 多实例、硬链接数据库别名或绕过应用的任意写入。不要删除仍在使用的锁文件来强行启动。品牌重试保留已有快照，不凭当前品牌猜测补齐历史已丢失的版本。

依赖审计为 0 只覆盖该日期 npm 的已知告警，不代表完整安全审计；Vite 维护状态与新公告仍需持续关注。测试中的模型响应、资料和审核均为合成或模拟，本轮没有验证真实供应商账单、客户材料、客户验收、付费、Docker 镜像运行或公网生产环境。自由问答仍有已记录坏例，不能宣称所有问题都能正确拒答。
