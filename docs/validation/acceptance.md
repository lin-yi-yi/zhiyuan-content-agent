- 安装并加载 `BAAI/bge-small-zh-v1.5`，实际产生 512 维语义向量；4 份演示资料入库，Qdrant 持久化索引与重启后查询成功。
- 启动脚本构建前端并在 `127.0.0.1:8765` 服务页面/API；健康、数据库就绪、资料列表及项目总览返回成功。
- 离线工作流产生草稿、卡片和 12 步记录，进入待人工审核；通过后重复审批被 409 拒绝。
- 真正调用已配置的 DeepSeek 回答“草稿审核通过后会自动发布到外部平台吗？”，约 2.22 秒返回回答与有效片段编号。只发送本项目人工演示资料。
- 真正执行 DeepSeek 内容工作流，21.40 秒进入待审核，草稿编号 2；同期 22 次健康检查，最长 8.72 ms。它是一次运行观察，不是并发压测或 SLA。摘要见 [运行记录](real-model-workflow.json)。
- Chrome 实际打开总览、资料查看/编辑、检索回答、固定样本评测、任务历史和审核；真实模型演示稿因标题/卡片质量问题被退回，界面显示退回状态与备注。生成完成不会自动视为审核通过。
- 实际在 Chrome 导出第 4 号演示稿的 ZIP：包含 3 张 PNG 和标题/正文/标签/评论引导文本，ZIP 完整性检查通过；打开证据卡 PNG 目视确认正文没有被省略。[导出记录](export.json)。
- 模型记录中存在本次真实调用的耗时和 token；API 不返回 prompt/response 原文。
- 最终重启后通过真实 HTTP 验证：创建 → 待审核 → 通过 → 编辑撤销批准 → 退回 → 重新提交 → 再次通过，重复批准返回 409。[生命周期记录](workflow-lifecycle.json)保留测试任务编号与状态。

## 检索实测与已知失败

报告：[rag-evaluation.json](rag-evaluation.json)。语料和问题来自项目人工编写的开发演示集，共 4 份文档、12 题，其中 8 题可答、4 题应拒答。使用真实 FastEmbed/Qdrant，回答端采用本地摘录，top_k=3、语义阈值=0.55。

| 指标 | 本次结果 |
| --- | --- |
| 候选文档 Recall@3 | 100% |
| 候选首位召回 | 87.5% |
| 候选片段精度 | 33.33% |
| 实际采用证据精度 | 77.78% |
| 实际采用证据召回 | 87.5% |
| 应拒答问题正确拒答 | 4/4 |
| 可答问题被接受 | 7/8 |
| 引用记录有效率 | 100% |
| 平均检索/摘录延迟 | 85.98 ms |

“没有相关资料时应该怎么回答？”本应找到引用规则文档并回答，但最高分未达到阈值，被误拒。此失败保留在报告中。部分相邻主题的片段也被采用；下一轮应增加真实问题与难负例，研究切块、检索排序和证据筛选，不能只降低阈值来追求满分。

引用有效率仅说明编号/来源记录可验证，不代表每句话均有证据支持。精度按报告定义计算，不能等同生成内容正确率；这组开发题不是独立测试集，不据此宣称生产准确率。延迟含本次运行状态影响，浏览器后续重复运行可能不同。

## 自动化检查

`./scripts/check.sh` 运行所有行为测试、Python 编译检查和前端 TypeScript/生产构建。本轮最终 **120 项测试通过**（5.64 秒），前端构建成功；测试覆盖：

- 文档去重、更新、删除、数据分组、索引指纹不兼容、引用和评测口径。
- 工作流条件分支、证据不足、事务回滚、重复派发、中断恢复、取消与失败重试。
- 审批内容快照、编辑撤销批准、退回重提、失效引用阻止批准。
- 真实 HTTP 服务中人为阻塞模型，查询与取消仍响应；不等于真实供应商压力测试。
- SSRF 私网与跳转检查、响应大小/超时边界、模型日志和未知异常脱敏。

测试中的语义合同使用合成向量和真实临时 Qdrant；上面的语义报告则实际执行了中文模型。测试有一条 Starlette/TestClient 的 httpx 弃用提示，不影响本轮结果，后续升级测试依赖时处理。

## 本次没有验证或没有实现的部分

1. Docker 文件、Compose 和 CI 工作流已提供；本机没有 Docker，容器构建及远程 CI 未执行。
2. BOSS 直聘为 10 条岗位线索：1 条部分正文、9 条摘要、0 条完整 JD。登录限制以内的信息才纳入分析，没有自动投递。
3. URL 抓取安全规则已通过可控测试；本机代理 DNS 将部分公网域名解析到保留地址，实际公网抓取被拒绝。可用粘贴正文/Markdown 导入，未降低防护。
4. Obsidian 为 Markdown 文件导入，未实现插件、双向同步或附件解析。
5. 默认单进程本地服务，没有账号体系、生产多租户授权、消息队列或公开托管；旧 MySQL 环境和其他外部模型未重新验收。
6. 保留旧版内容编辑/导出和指标页面；本轮验收资料→检索→草稿→审核及一套真实 PNG/ZIP 导出，未逐一回归旧版所有模板和复盘统计。
7. 卡片摘要硬截断问题已在浏览器验收中发现并修复，新增断句与引用回归；同时修复了证据卡导出的段落高度估算，新稿实际导出后已目视核对。此前生成的第 2 号稿件保留为退回案例，不会悄悄改写它的内容与审核历史。
