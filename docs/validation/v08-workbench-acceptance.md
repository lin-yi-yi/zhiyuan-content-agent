## 本轮真实业务验收

验收使用独立 8767 服务，数据位于 `.data/v08-acceptance/`。测试资料全部人工合成，不把日常知识库中的旧资料传给远程模型，不向外部平台发布。验收后关闭临时服务；8765/8766 使用各自原有数据目录。

### PDF 和 DOCX

- PDF：独立知识库 3；预览 HTTP 200、未入库；确认 HTTP 201，文档 1、一块；真实 BGE + Qdrant 命中，分数 0.8362。无文字 PDF 返回 HTTP 422，说明暂不支持 OCR，未生成资料。
- DOCX：独立知识库 4；预览 HTTP 200，保留表格中的文字；确认 HTTP 201，文档 2、一块。混合检索两路均排名第一，RRF 0.03279，证据门通过。
- 单文件 1 MiB、PDF 50 页、正文 120,000 字符。解析限制并发、耗时及解压规模；DOCX 图片、批注、页眉页脚和复杂版式不保留；扫描件不做 OCR。
- **浏览器上传按钮未完成端到端验收**：扩展文件选择工具缺少 file-URL 权限，系统选择框工具也不可用。上面的 PDF/DOCX 结果来自真实 HTTP 预览/入库接口；页面端改用粘贴正文完成后续流程，不混称文件上传已全部验收。

证据：`.data/v08-acceptance/pdf-check.json`、`docx-check.json`。

### 浏览器创作与交付

1. 在页面创建知识库 2，粘贴合成操作手册，预览后确认入库，建立两个真实语义片段。
2. 点击“用资料提问”，地址为 `#rag?kb=2`，知识库不丢失。使用 DeepSeek 提问退回后的重提流程，回答有 `[chunk:3]` 引用，与合成原文一致。
3. 页面切换混合检索并只查看结果，显示融合排序分 0.0328，与语义分分开。
4. 在知识库 2 创建 DeepSeek 内容任务 1，地址自动记录 `#agent?run=1`，产生稿件 1 和四张卡片。步骤耗时合计约 25.17 秒。
5. 浏览器退回并写修改意见；页面可见该意见。进入 `#drafts?draft=1&run=1&topic=1`，修改正文、最终标题、封面短句和封面卡片。
6. 保存→返回任务 1→重新送审→人工批准。审核历史保留；修改前评分失效；批准说明明确“仅合成功能验收”。
7. 刷新编辑地址仍读取指定稿件。实际下载 ZIP **424,179 字节**，包含四张 **900×1200 PNG** 和正文、标题、标签、评论引导；已打开第 2/3 页检查，没有文字溢出。标题清单首项是用户最终选定标题。

本轮问答加工作流共 **7 次真实 DeepSeek 调用成功**，问答调用约 1.406 秒。卡片分页、一次规则修订依然是本地代码，不声称所有节点均由大模型生成。

中间质量评估从 68 到 72/100，仍低于流程参考线 75；这是模型辅助评分，不是客观质量提升证明。后续人工修改让该评分失效。卡片仍采用原文节选及内部引用标记，公开发布前需要编辑，不应把“已审批的合成测试”当成真实客户内容验收。

证据：`.data/v08-acceptance/workflow-initial.json`、`workflow-approved.json`、`model-calls.json`、`export/v08-content-package.zip`。

## 混合检索的实测取舍

独立真实 BGE/Qdrant 对照：7 份合成资料、21 题（15 可答、6 应拒），结果不能外推成真实用户准确率。

| 指标 | 语义 | 混合 | 词项 |
| --- | ---: | ---: | ---: |
| 候选 Recall@3 | 1.0000 | 0.9333 | 0.9333 |
| 回答采用证据召回 | 0.6667 | 0.9333 | 0.8667 |
| 应拒答题拒答比例 | 0.8333 | 0.8333 | 1.0000 |

融合减少一些编号问题的误拒，但损失一个候选召回样本，并仍错误放行一道退款签名问题。保留语义默认，不把 RRF 分数当作置信度。详见 [混合检索研究与坏例](../research/v08-hybrid-retrieval.md)。
