# 知源：项目状态与分支说明

更新日期：2026-10-03。当前代码版本：**v0.10，本地验证版**。

## 项目做什么

面向小型工业 B2B 内容团队，把一个品牌有权使用的产品资料整理成 FAQ／售前答疑内容包。主要流程是：资料与事实核验 → RAG 检索 → LangGraph 内容生成与检查 → 人工审核 → 可追溯 Markdown 交付。

项目包含品牌简报、知识库、内容任务、稿件与卡片编辑、组织隔离和人工试点记录。当前重点是完整交付一个有依据的内容包。

## 尚未完成

- **GitHub Actions 首次验收**：已补齐发布权限并配置 `Project checks`，推送和 Pull Request 会执行安装、后端测试、前端测试及构建；[远程运行记录](https://github.com/lin-yi-yi/zhiyuan-content-agent/actions/workflows/check.yml)的首次结果待确认。
- **真实模型与费用核对**：本轮追踪逻辑未调用付费模型，也未接入供应商账单；输入/输出 token 的统一单价估算不覆盖所有计价方式。
- **真实客户材料与验收**：固定评测材料是自编合成数据，标签待人工复核；没有客户付费、复购或 ROI 证据。
- **外部业务入口与运维**：尚未确定具体平台及负责人，未做真实平台回写、公网部署或生产恢复验收。

已有实现与待完成事项分开记录，不把内部审核通过当作客户通过，也不把测试通过当作生产上线。

## 下一步顺序

1. 选定一位资料负责人、一个品牌及有权使用的资料，核对真实历史任务与验收口径。
2. 明确一个实际业务入口后，验证请求进入、范围、幂等、失败回执及批准版本回写。
3. 在明确费用上限和资料外发范围后，验证一次在线调用及供应商用量对账。
4. 完成隔离部署和备份恢复演练，再决定是否进入真实小团队试点。

当前可立即复现的入口是 [安装与运行](../SETUP.md) 和 [工业 FAQ 练习](industrial-faq-practice.md)。
